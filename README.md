# Вишлист Владимира

Сайт: https://vsokhrin.github.io/wishlist/

## Как добавить желание

Открой файл [`wishes.json`](wishes.json) → карандаш «Edit» → добавь объект в список `wishes` → «Commit changes». Через минуту сайт обновится.

```json
{
  "currency": "₽",
  "categories": ["Клавиатуры", "Мыши", "Звук"],
  "wishes": [
    {
      "category": "Клавиатуры",
      "title": "NuPhy Air75 V3",
      "note": "Тонкая беспроводная клавиатура",
      "price": 9500,
      "image": "https://…/photo.jpg",
      "links": [
        { "shop": "Авито", "url": "https://www.avito.ru/…", "price": 9500 },
        { "shop": "KNS", "url": "https://www.kns.ru/…", "price": 14006, "note": "под заказ" }
      ],
      "search": "NuPhy Air75 V3",
      "priority": 3
    }
  ]
}
```

| Поле | Что это | Обязательно |
|---|---|---|
| `category` | Раздел. Порядок разделов задаёт список `categories` вверху файла; раздел, которого там нет, встанет в конец | нет |
| `title` | Название | да |
| `note` | Пояснение: цвет, размер, модель | нет |
| `price` | Цена справа, числом без пробелов. Лучше ставить самую низкую из найденных | нет |
| `image` | Ссылка на картинку или путь к файлу в репозитории, например `images/keyboard.jpg` | нет |
| `links` | Магазины: `shop` — название, `url` — ссылка, `price` и `note` — по желанию | нет |
| `search` | Текст для поиска. По нему сами появятся ссылки «Искать на Яндекс Маркете / Ozon / Авито» | нет |
| `searchIn` | Где искать, если нужно иначе: любые из `"market"`, `"ozon"`, `"avito"`, `"ali"` (AliExpress) | нет |
| `gone` | `true` — объявление, которое я сохранил, уже сняли; под желанием появится пометка | нет |
| `priority` | `3` — «Очень хочу» (штамп и наверх раздела), `2` — повыше, `1` — обычное | нет |
| `status` | `"reserved"` — уже кто-то дарит, `"gifted"` — подарено | нет |

Между объектами — запятая, после последнего — нет. Старое поле `link` (одна ссылка) тоже работает.
