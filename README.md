# Вишлист Владимира

Сайт: https://vsokhrin.github.io/wishlist/

## Как добавить желание

Открой файл [`wishes.json`](wishes.json) → карандаш «Edit» → добавь объект в список `wishes` → «Commit changes». Через минуту сайт обновится.

```json
{
  "currency": "₽",
  "wishes": [
    {
      "title": "Механическая клавиатура",
      "note": "Коричневые свитчи, с кириллицей",
      "price": 8990,
      "link": "https://www.ozon.ru/product/...",
      "image": "https://…/photo.jpg",
      "priority": 3
    }
  ]
}
```

| Поле | Что это | Обязательно |
|---|---|---|
| `title` | Название | да |
| `note` | Пояснение: цвет, размер, модель | нет |
| `price` | Цена числом, без пробелов | нет |
| `link` | Где купить | нет |
| `image` | Ссылка на картинку или путь к файлу в репозитории, например `images/keyboard.jpg` | нет |
| `priority` | `3` — «Очень хочу» (штамп и наверх списка), `2` — обычное, `1` — если будет повод | нет |
| `status` | `"reserved"` — уже кто-то дарит, `"gifted"` — подарено | нет |

Между объектами — запятая, после последнего — нет.
